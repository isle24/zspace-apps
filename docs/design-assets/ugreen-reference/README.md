# 绿联云（UGREEN NAS）影视 / 音乐 界面参照

来源：用户本机绿联云 NAS `192.168.3.57`（sshbind 别名 `4300plus`）。
它的影视 / 音乐是**独立前端**，由 NAS 直接提供：

```
https://192.168.3.57:9443/music/     ← 可以独立打开（自签证书，需忽略证书错误）
https://192.168.3.57:9443/video/     ← 依赖 Electron 客户端桥接，独立打开是空白
```

| 文件 | 内容 |
| --- | --- |
| `ug-music-library.png` | **绿联音乐** 主界面（空库状态，1440×900@2x） |
| `ug-video-empty.png` | 影视子应用独立打开的效果 —— 只有客户端外壳，**内容区空白**（需要客户端注入的桥接） |

## 从截图量到的结构（音乐）

- **左侧栏约 215px**，纯白（`#fafafa`），与内容区（`#ffffff`）几乎同色、靠一条极淡的分隔线区分；
- 侧栏顶部：应用图标 + 「音乐」标题；
- 搜索框：圆角 6px、浅灰底、占满侧栏宽度；
- 导航项（Library / Folders / Albums / Genres / Artists）**每项带图标**，
  选中态是**浅蓝圆角块**（`#ecf5fb`）+ 蓝色图标与文字 —— 不是实心高亮；
- 分组标题（`My` / `Playlist`）是小号灰字，`Playlist` 右侧带 `+`；
- 内容区：页面标题「Library (0)」（约 24px，粗体）+ 居中空状态插画；
- **底部一条居中的播放条**：左「上一首 / 播放 / 下一首」，右侧「收藏 / 循环 / 音量 / 速度 / 队列」；
- 整体是**浅色、留白多**的风格，与我们现在深色高密的列表差别很大。

## 怎么复现这些截图

```bash
# 1) 用带调试端口的 Chrome 打开（需要忽略自签证书）
node /tmp/ug-shot.mjs 9333 "https://192.168.3.57:9443/music/" /tmp/ug-music.png
# 2) 直接取前端资源（CSS/HTML）
curl -sk https://192.168.3.57:9443/music/ | grep -oE 'href="\./css/[^"]+\.css"'
```

## 注意

- 登录 / 数据都需要设备侧会话，**这里只参照界面结构，不复制其代码或素材文件**；
- 影视子应用拿不到可用截图（`ug-video-empty.png` 就是空白效果），
  它的版式只能从 CSS 与用户截图推断。
