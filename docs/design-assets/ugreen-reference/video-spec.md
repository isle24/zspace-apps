# 绿联影视中心：逐屏规格（据用户 2026-10-12 截图）

> 截图是用户自己库的内容，**不入库**。这里只记结构与尺寸，作为 1:1 复刻依据。
> 截图窗口约 1596 逻辑宽，下列比例按截图像素折算。

## 1. 整体外壳

- **左侧栏**：约占宽度 **20%**（≈300px @1440）。深色半透明，压在内容背景之上；
  顶部是 macOS 红黄绿按钮区（客户端自带），其下依次是：
  - 一组**主导航**（图标 + 文字，每项高约 56px）：
    `首页` `最近播放` `我的收藏` `文件夹` `合集`
  - 分组标签 `媒体库`（小号灰字），下面是各媒体库（图标是**圆形胶片盘**）：
    `strm电影电视剧` `河蟹` …
  - 分组标签 `分类`，下面是 `全部` `电影` `电视剧` `其他`（每项带图标）
- **选中态**：不是一个实心蓝块，而是**圆角矩形浅色底**（约 8px 圆角，半透明白）+ 亮一点的文字与图标。
- **顶部工具条**：`←` `→` `⟳` 三个圆形按钮 + **居中搜索框**（圆角胶囊、深灰底、放大镜 +
  「搜索（⌘ K）」占位）+ 最右 `⚙`。整体浮在内容之上（首页时会与被背景图叠在一起）。

## 2. 首页

- **全宽 hero**：一张 backdrop 铺满顶部约 **55% 高度**，底部渐变过渡到页面背景。
- 左下：标题（**约 46px，白色粗体**）→ 元信息行（`2008 · 冒险 · 科幻 · 动作`）→
  两行简介（超出省略）。
- 标题下方一枚 **播放按钮**：深色半透明胶囊（约 220×64，圆角 8px）+ 白色播放图标 + 「播放」。
- **轮播圆点**：底部居中，5 个，当前项是长条（约 28px），其余是 6px 圆点。
- 下方内容区：`最近播放 ›` 标题 + **横版缩略图行**（16:9，左下角有**蓝色进度条**）。

## 3. 「最近播放」等列表页

- 内容区左上角是**页面标题**（`最近播放 (2)`，约 24px 粗体）。
- **横版卡片网格**：卡宽约 380px，16:9 缩略图（圆角 8px），下方标题（粗体约 18px）+
  灰色小字元信息（`第1集 · 共9集`）；缩略图底部有蓝/灰进度条。

## 4. 「文件夹」页（媒体库封面）

- 同样是网格，但封面是**横向 3 连图**（约 400×215，圆角 8px）：
  取该库前 3 张海报**并排裁剪**；不足 3 张时留深灰占位（带一个播放图标）。
- 封面下：库名（粗体）+ `共 N 项`（灰色小字）。

## 5. 「合集」页 / 媒体库页（海报墙）

- 右上角**工具条**：`+`（新建）、排序、**网格视图**、**列表视图**、`…`（更多），
  5 个约 44×44 的圆角方形按钮，深灰底。
- **海报网格**：海报是 **2:3 竖版**，约 **176px 宽**（CSS 里 `minmax(176px, 1fr)`），
  圆角 8px；**评分徽标**在海报右下角（橙色，如 `9.0`）。
- 海报下：标题（约 18px 粗体）+ 元信息（`2026 · 共7集`，灰色小字）。
- **列表视图**：左海报 + 右侧标题 / 元信息 / 简介 + **蓝色播放按钮**（胶囊，蓝 `#2F6BFF` 系）+
  `…` 圆角按钮。

## 6. 详情页

- 顶部同样是**大 backdrop**，底部渐变过渡；左侧栏仍在。
- 蓝色**播放按钮**（`第 2 集`，胶囊，约 200×56）+ 一排圆形图标按钮（已看 / 收藏 / 历史 / 更多）。
- 元信息行：`★ 9.0   2026（中国大陆）   总7/60集   ◎ strm电影电视剧`。
- 简介段落（灰白）。
- `选集`：**数字方块**,约 48×40、圆角 8px，当前集为蓝色实心；右侧有视图切换图标。
- `演职人员信息`：**圆形头像**（约 96px）+ 姓名，横向排列。

## 7. 播放器（独立窗口）

- 顶部标题栏显示 `剧名-S1:E2-集名`，右侧一个「钉住」图标。
- 舞台纯黑，中央加载态（转圈 + 「加载中…」）。
- **控制条**（贴底）：左 `⏮` `-15s` `▶` `+15s` `⏭`；右侧 `🔊` 音量、
  `原画`（画质）、`1.0x`（倍速）、`CC`（字幕）、`PiP`、`全屏`、`⚙`、`☰`（播放列表）。
- 进度条在控制条**上方**，两端各有一个时间码（`00:00:00`）。
