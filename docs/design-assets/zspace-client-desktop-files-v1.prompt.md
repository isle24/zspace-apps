Use case: ui-mockup.
Image 1 role: exact visual-system reference for the same complete ZSPACE client. Keep window size, chrome, cold-white/grey surfaces, system blue #0A64D8, typography, blue cube identity and the same sidebar geometry.
Asset: a polished Mac desktop file-browser screen, not a real NAS screenshot. Landscape 16:10, straight-on single window fills 94% canvas, subtle shadow and neutral margin. Identity "空间客户端" with small "极空间". Sidebar groups and entries exactly like reference: 常用 / 空间首页, 文件, 相册, 影视, 音乐; 应用 / 下载, 应用中心, 任务中心; 设备 / 设备与设置. Select "文件" in pale blue. Bottom tile "我的 NAS" and "待连接".
Main toolbar: compact back and forward controls, breadcrumb "我的文件 > 工作资料", a search field "搜索当前目录", view toggle and a small detail-pane toggle. All on one restrained line.
Content title "工作资料" with small subdued badge "示例内容". Secondary compact toolbar: file filter segments "全部", "文档", "图片", "视频", with "全部" selected; right aligned sort control "名称". A small grey disabled upload control "上传" with no destructive actions.
Main layout Finder-like file table 70% width plus collapsible inspector 30% width. Table has quiet column headers "名称", "类型", "修改日期", "大小". Fine separators, ample compact row height, beautiful native-style document and folder icons, precise text alignment. Rows are entirely fictional design samples:
"设计素材" / "文件夹" / "示例" / "—";
"项目文档" / "文件夹" / "示例" / "—";
"旅行照片" / "文件夹" / "示例" / "—";
"产品方案.pdf" / "PDF 文档" / "示例" / "示例文件" selected with delicate pale-blue background;
"会议记录.docx" / "Word 文档" / "示例" / "示例文件";
"界面参考.png" / "图像" / "示例" / "示例文件".
Do not fabricate real NAS sizes, usernames, timestamps, paths, usage or connection success.
Right inspector title "文件详情". A beautiful restrained preview thumbnail of an original sample document, heading inside "产品方案", a few neutral short lines and simple diagram shapes, not a photo of paper. Below name "产品方案.pdf", muted "示例文件", small property rows "类型 / PDF 文档", "位置 / 工作资料", "权限 / 连接后读取". A slim modest blue "打开预览" control and grey "下载" control. Inspector has clear breathing room and logical grouping, no giant blank blocks.
Bottom status bar unobtrusive "示例内容 · 连接 NAS 后显示真实文件". No delete, clear, format, trash or overwrite actions. All functional data is illustrative.
Typography human-scale, exquisite Mac utility proportions, modest 8px controls/12px containers, one coherent thin-line icon family, consistent color tokens. No Windows controls, thick outlines, oversized forms, decorative analytics, fake ratings or dashboard gradients.
Outside the window the small caption "设计预览 · 示例内容". Render all Chinese labels accurately and preserve the reference style.
