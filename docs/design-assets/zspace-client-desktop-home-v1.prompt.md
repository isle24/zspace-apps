# home 桌面客户端设计提示词

完整提示词：

Use case: ui-mockup.
Image 1 role: style reference for an expanded product, not an edit target. Keep its beautiful Macintosh window proportions, cool-white surfaces, restrained light grey sidebar, compact toolbar, graphite typography and system-blue accent. Build a new full NAS client, not just the store.
Asset: one high-fidelity Mac desktop client home screen for ZSPACE NAS. User wants all major modules redesigned: home, files, photos, videos, music, downloads, apps, tasks and settings. These are conceptual UI designs only, not live NAS screenshots.
Composition: landscape 16:10 straight-on application window filling 94% of canvas, pale neutral background margin, delicate shadow, 18px window corners, Mac traffic lights top-left. No hardware mockup, no perspective. Same 54-60px compact toolbar as reference and 220px sidebar. Cold white #FAFBFC, soft grey #F0F2F5, graphite #202328, accent system blue #0A64D8. Human-scale crisp PingFang/SF-like Chinese type, body equivalent 13-14px, section headings 18px and page heading 26px. Fine line icons from a coherent single family, original app icons where applicable. No dramatic gradients or thick card borders.
Identity top left "空间客户端" and small supporting text "极空间". Sidebar groups: "常用" containing "空间首页" selected pale-blue, "文件", "相册", "影视", "音乐"; "应用" containing "下载", "应用中心", "任务中心"; "设备" containing "设备与设置". Keep rows compact and precisely aligned. At bottom device switch tile "我的 NAS", grey "待连接" and a subtle chevron.
Main toolbar title "空间首页", small sidebar toggle, broad search field on right "搜索文件、照片或应用", avatar circle outline. Single tidy row.
Main content 32px inset. Heading "我的空间". Short muted description "文件、媒体与应用，一处管理". Compact quiet connection strip with a device icon, text "连接 NAS 后显示设备信息" and a small blue "连接设备" button at far right. Do not show fake connection success, disk capacity, CPU data or counters.
Below a beautifully composed six-item quick-entry grid, 3 columns by 2 rows, low broad flat tiles with white/very-pale backgrounds and modest 12px corners. Each has a carefully proportioned colorful icon and name and one muted caption: "文件" / "浏览你的资料"; "相册" / "时间线与相册"; "影视" / "私人影视库"; "音乐" / "随时聆听"; "下载" / "任务与进度"; "应用" / "应用桌面与商店". Colored icons do not turn the entire tiles colorful. The grid feels like a refined Mac launchpad integrated into a useful application.
Lower main area is a balanced 2:1 split. Left section title "最近访问" with small grey qualifier "示例内容", containing four compact list rows with appropriate document/folder icons and only file names "产品方案.pdf", "会议记录.docx", "旅行照片", "设计素材". Keep secondary labels simple "文档", "文档", "相册", "文件夹", no made-up timestamps, usernames or personal NAS paths. Right column two understated blocks: "设备状态" with "连接后显示" and subtle hardware outline; "任务" with neutral "暂无任务" and small "查看任务" action. No decorative analytics charts.
All spacing, icon sizes, text baselines and controls feel exact, quietly premium, like a real polished Mac utility. No giant marketing headline, no persistent install panel. Include all module entries clearly. Keep original official webpage solely as a small neutral optional menu item at bottom of settings menu only if space, not as a main module replacement.
Outside the window, at bottom, small exact caption "设计预览 · 示例内容". Use fictional original example content only; never depict a real account or credentials. Render labels precisely, no extra slogans, no fake API success, no destructive actions, no delete/format/clear buttons.
