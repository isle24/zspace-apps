Use case: ui-mockup. Image 1 role: exact style reference for the complete ZSPACE client. Keep the same Mac window chrome, blue-cube identity "空间客户端" with small "极空间", 220px grouped sidebar, compact toolbar, crisp PingFang/SF-like Chinese typography, cold white #FAFBFC, pale grey #F0F2F5, graphite #202328 and single system-blue accent #0A64D8. Single straight-on landscape 16:10 window filling 94% canvas, pale neutral margin and delicate shadow, no hardware mockup. Sidebar exact entries 常用 / 空间首页, 文件, 相册, 影视, 音乐; 应用 / 下载, 应用中心, 任务中心; 设备 / 设备与设置. Bottom device tile "我的 NAS" and "待连接". All displayed media is original fictional sample content for UI design, not actual NAS data. Outside window small caption "设计预览 · 示例内容". No delete, format, clear or destructive actions; no actual connection success, usage counts, ratings or private account information. Human-scale readable text, carefully aligned controls, subtle borders and generous but practical spacing.
Primary asset: a refined full Mac NAS music-library interface and integrated player. Select "音乐" in sidebar. Toolbar title "音乐", search "搜索歌曲、专辑或歌手" on right and two restrained controls.
Content heading "我的音乐", quiet badge "示例内容". Compact library filters "歌曲", "专辑", "歌手", "歌单", with "专辑" selected.
Top section "专辑": four beautifully art-directed square ORIGINAL album covers using restrained nature/abstract images, names "山间来信", "城市漫游", "蓝色午后", "海风". Small grey artist line "示例音乐" below each. No real artist identities or copyrighted album covers.
Lower section "歌曲" has an elegant compact table with columns "歌曲", "专辑", "时长". Rows with fictional names "晨光" / "山间来信" / "示例"; "微风" / "蓝色午后" / "示例"; "夜行" / "城市漫游" / "示例"; "潮汐" / "海风" / "示例". The first row is delicately selected.
Full-width compact player at the window bottom, integrated into the app chrome: small square cover, "晨光", artist "示例音乐", previous/play/next controls, restrained scrub line at start, volume, queue and lyrics icons. Show a play triangle (paused), no playback progress or a fake currently streaming status. A small right lyric preview titled "歌词" with text "连接后读取" may be visible if it fits without crowding.
This is a native redesign of music browsing and player UI, not an official webview. It should feel like a beautifully made Mac music utility, with coherent typography, subtle affordances and no oversized colored shapes.
