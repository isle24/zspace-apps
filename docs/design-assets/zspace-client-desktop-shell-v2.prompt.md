完整提示词：

Use case: ui-mockup.
Image 1 role: a structural reference for a NAS system desktop. Create a NEW original design for a third-party ZSPACE client called "空间桌面". The user explicitly wants a SYSTEM DESKTOP with wallpaper, app icons, status bar and windowed applications. Preserve that desktop interaction model, do not create a sidebar dashboard. Do not copy any UGREEN logo, real addresses, account names, commercial wallpaper or exact proprietary icons.
Asset: one high fidelity Mac-hosted NAS system desktop concept, landscape 16:10, straight-on full application canvas with modest 14px outer rounded corners, fills almost the entire frame. No laptop, no perspective, no marketing page.
Wallpaper: original sophisticated midnight-navy and muted sapphire folded silk-ribbon landscape, broad smooth sculptural waves, beautifully lit subtle blue edge highlights with a calmer very dark upper region for icon legibility. Distinct original artwork, not a trace of the reference. Wallpaper extends behind the whole desktop. No white content area, no persistent left sidebar, no large dashboard cards.
Top: thin semi-transparent dark system status bar 44px tall. Mac traffic lights at far upper-left as host-window controls, next a small desktop-view/launcher icon pair, subtle title "空间桌面". Right area: current device "我的 NAS", connection "待连接", small "CPU —" and "RAM —" readable indicators, then tiny consistent line icons for tasks, notifications, search and account. No real usage numbers or network speed. Avoid crowded metrics.
Desktop: arrange twelve lovely large original app icons in a tidy 4-column by 3-row grid occupying the upper-left and center-left 60% of the desktop, leaving intentional beautiful wallpaper breathing space on right. Icons roughly 70px, modest glossy/material craft with familiar shapes but original assets. White readable 15px labels beneath each, light text shadow. The grid must look like a NAS operating-system desktop, not card tiles. No cards or borders around app icons.
Exact icon labels:
row 1 "文件管理", "相册", "影视中心", "音乐";
row 2 "下载中心", "应用商店", "控制面板", "任务中心";
row 3 "存储管理", "Docker", "虚拟机", "远程访问".
File icon golden folder, photo icon blue/teal landscape, video icon violet clapper/play, music icon coral note, download green arrow, store blue-white package, control panel silver sliders, tasks blue graph/list, storage charcoal drive stack, Docker recognizable whale concept, VM blue layered squares, remote globe/network. Consistent crafted icon proportions and cohesive style; no random decorative labels.
Bottom: a compact centered translucent dark Dock with favorites "文件", "相册", "影视", "音乐", "商店", "设置" represented by small icons and one subtle separator before a show-desktop icon. Small hover tooltip "应用商店" may be shown above one dock icon. Dock must float cleanly with enough bottom safe margin and not obscure desktop icon labels.
This screen depicts the desktop with NO open app windows, NO install drawer, NO file table, NO dashboard. It is the home environment from which users launch multiple independent applications.
At very bottom-left, tiny unobtrusive caption "设计预览 · 未连接 NAS". Render Chinese labels precisely and readable. No destructive app such as trash/format/cleanup, no user credentials, no fake installed/running status. The design should feel elegant, calm, expertly spaced and polished like a premium NAS system desktop, combining the reference's desktop concept with the earlier project's Mac-level craft.
