# 飞牛参考 UI 与文件存储入口

用户2026-10-11明确要求把存储池放入文件管理左边菜单，提供已登录飞牛虚拟机界面作为设计，允许完整仿照；目标更新为“参考飞牛ui 完成pc客户端 和 独立应用商店的实现”。本设计落实该已选方向，保留完整客户端、独立商店、官方5055直连与禁止删除资料的范围。

## 已观察的参考

已只读查看用户的Chrome飞牛桌面、文件窗口和后面的应用中心。参考截图保留在 `output/verification/20261011-fnos-files-reference.png`，没有输入/存储凭据、安装应用或创建存储空间。虚拟机尚无存储空间，因此参考仅证明界面结构，不证明其存储池树或极空间的数据结构。

参考特征：左侧窄应用栏、桌面图标、可重叠的应用窗口；浅灰标题栏与窗口外壳、白色内容面、约230px应用内侧栏；顶部路径和搜索；蓝色选中文字与浅色选中行、轻边框、清晰的留白。继续使用本项目品牌和图标资产。

## 文件窗口优先实现

当前 `OfficialNas.read('files.roots')` 已按官方polling.pools筛选mounted池，以经过验证的key映射官方个人目录入口，返回真实Item{id,name,path,kind,metadata}。UI只消费返回Item，不能通过池名称、盘序号或参考飞牛路径猜测极空间路径。

文件左栏保留“我的文件”“最近访问”，新增永久可见的“存储池”分组，逐个列出官方返回的可访问池。名称来自真实name；点击进入该Item的实际path。导航、搜索和最近访问时继续展示池入口；新账号/断开时清空旧池数据。选中状态按实际根与目录路径的组件边界匹配，不把同前缀的其他路径混为同一池。加载、失败、未连接与无可访问池状态真实可见，支持独立刷新。

文件窗口采用飞牛式浅灰侧栏、白色主面和紧凑路径工具栏，改善现有大标题/多层工具栏间距；保留真实搜索范围与索引说明、分页、详情、预览、下载和新建目录。当前“返回上一级”保持真实语义；不添加没有功能的前进、共享、回收站或管理员按钮。桌面/H5共同使用文件模块，窄屏位置入口可折叠但仍可找到，正文不横向溢出。

这项改动只调整读取和导航视图，不修改SDK协议、NAS挂载/权限/文件，也不接管虚拟机或使用飞牛接口替代极空间接口。

## 后续连续实现

上传引擎通过独立审查后接入全局任务与文件动作，延续此文件窗口风格；生产不存在响应未核实的状态继续诚实停止写入。随后调整桌面应用栏/应用窗口和独立商店分类布局，使客户端与商店沿用同一飞牛参考语言。底层授权、独立商店登录与客户端NAS管理员复用保持当前契约；真实安装初始化和官方入口仍要完成。

移动当前为H5，PC为Tauri；不引入Flutter。桌面视觉调整不改变目录和文件；手机版仍使用可读的单列、实际操作按钮和44px触控尺寸。light/dark沿用共享CSS变量，导航图标沿用Phosphor，现有目录对话框键盘/焦点和账号隔离不退步。
