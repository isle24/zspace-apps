# 第三方客户端验收修复

根据用户本轮直接修复授权，延续已确认的 React/Tauri 桌面设计及官方 NAS SDK。客户端分支 `feat/pc-store-h5` 当前干净；本轮继续整合独立空间商店，并按用户最新参考扩展媒体及 Docker 操作。

应用商店读取原生和容器两个来源各一次，按设备提供的中文名称、简介、图标、类别及安装状态展示。提供发现、分类、搜索、已安装、详情及已验证协议的安装/启停流程。安装先检查依赖、选择设备返回的磁盘；写入后读取应用及任务状态，不能用 HTTP 成功代替安装完成。设备未返回入口时不猜 URL。

控制面板用概览和中文功能入口，设备应用复用商店界面；系统设置以确认过含义的控件呈现，仅允许官方静态源已确认参数。保存读取设备确认，失败保留编辑内容；未知字段不进入用户主界面。

Docker 同源适配器需校验当前 NAS 身份，写操作必须管理员及跨站防护。容器提供状态、端口、详情、日志、启动、停止、重启、暂停及恢复。禁止数据删除和通用命令执行，保护客户端自身容器。控制绑定完整容器 ID，服务端回读实际状态，界面显示请求、回读及失败。修正真实端口字段；切换视图、断开会话及关闭日志时丢弃旧响应。新增容器使用现有镜像和命名数据卷，参数为中文表单。

验收脚本必须保留各命令退出码，失败/未登录/未执行不能统计为通过。新增回归先失败再实现；执行前端全量单测、类型构建、Go 接口测试、浏览器宽窄布局及实际 NAS 回读。真机写入仅用专门验收容器/可还原个人设置，不启停已有业务服务，不删除用户数据。记录未完成的原生/外部服务证据，不扩大成功声明。


## 用户补充范围

相册沿用 NAS 真实数据，以绿联参考的左侧分区、紧密缩略图、年份导航及网格尺寸为布局。补宝宝相册（官方 type=60）、共享相册、收藏、文件夹及智能分类；使用已验证接口读取，普通相册与宝宝相册的创建以官方实际字段校验。重复照片仅在设备提供明确分组时展示，不能把相似判断等同文件名相同。

资源挂件支持指针和触摸拖动、视口边界约束、位置保存和键盘移动，展开操作与拖动区分；移除系统栏重复时间及背景层。

音乐以 QQ 音乐的侧栏、专辑封面、曲目表、绿色播放操作和大封面播放器组织。封面使用 NAS 提供或歌曲文件内嵌图片，失败可见并保留占位；不借用不相关网络图片。播放使用现有已验证路径。

Docker 创建 Compose 支持 YAML 编辑和导入、验证/预览、实际部署及状态回读；写入仍要求 NAS 管理员。应用普通 Compose 配置且明确提示不支持字段；禁止静默丢弃危险或未知配置、禁止宿主路径和任意命令执行接口。镜像按仓库标签、人类可读元数据命名，无标签条目说明而非仅显示 ID。

空间商店图标、应用说明和版本目录存入 GitHub 公共仓库。允许使用 nj-game 新建测试后台和 zstore.2iwm.com 反向代理，不查 DNS，不改已有业务服务。中央目录及后台与 NAS 本地安装运行区分，后台统一要求登录，NAS 身份复用失败时保留独立登录。

## 普通用户安装交付

按用户补充要求，提供 Linux amd64 预编译 Docker 安装包与 `install-docker.sh`。安装目标只需 Docker 27.3 或以上及常见 Linux shell 工具；不依赖 sshbind、主机 Python、Go 或 Node。脚本检查发布校验和，基于包含已编译程序的 Dockerfile 构建本地镜像，再创建独立商店运行服务及客户端代理。指定 NAS IP、数据盘路径；只创建不存在的专用目录与容器，生成服务身份记录，保留所有安装或失败资源。不覆盖已有路径/服务，不删除数据。Docker 服务本体以普通 NAS UID/GID 运行，Socket 组权限明确配置。升级流程不通过重新运行安装脚本强行替换。
