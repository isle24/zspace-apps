# 旧版 Docker 与 SSH 一键安装

用户要求兼容 Docker 26，并扩展到 24 或更旧版本，将 SSH 一键安装入口部署到 zstore 域名。Docker 官方无 22.x 引擎系列，最低目标定为 20.10（API 1.41），覆盖私有 cgroup 命名空间所需的能力。

保留镜像内固定且校验过的 Docker CLI 27.3.1、Compose 2.32.4，由客户端自动协商宿主 API；禁止固定较高的 DOCKER_API_VERSION。移除 27.3 硬性拦截，拒绝 20.10 以下或格式不明的版本。目录、非递归挂载、只读根目录、所有权和容器身份限制保持原有语义。若实测某旧版本无法满足能力要求，应明确拒绝而非隐式放宽限制。

新增 POSIX shell 安装脚本，默认安装 UI 和独立商店，可选择只装商店。通过镜像内固定 Compose 执行，不要求宿主安装 Compose、Python 或构建工具；检测本机 Docker 和局域网地址，拒绝占用的项目及持久资源，失败保留数据。首次管理员账号在网页创建。发布 HTTPS /install.sh 和对应文档，不改变现有后台 API、账号和数据库。

验收必须区分单元测试、真实隔离旧引擎的创建/启动/接口及升级行为、当前 NAS 的回归、DockerHub 标签与公网脚本下载。现有 NAS 引擎不降级，不用真实数据做旧版实验。
