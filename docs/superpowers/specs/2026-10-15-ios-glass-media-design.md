# 影视与音乐的 iPhone 玻璃风格

用户已选择完整方案：采用 Apple TV 与 Apple Music 的信息层次，统一影视、音乐、播放器的材质、圆角和深浅色；同时修复实际 UI 问题。

## 目标与边界

- 影视首页保留跨左右区域的全局海报背景，正文与控件靠渐变遮罩和磨砂层保证可读。
- 音乐改为封面主导、紧凑曲库、悬浮播放条；桌面保留侧栏，窄屏使用紧凑横向导航。
- 玻璃用于标题栏、导航、搜索和播放控件。歌曲文字、海报与专辑封面保持清楚，不把所有内容变成透明叠层。
- 只修改客户端呈现与已确认的音乐元数据错误；保留 NAS 官方接口、权限、分页、媒体选择与播放请求。
- 不增加不存在的收藏/历史/推荐数据。所有数量和封面来自 NAS；缺少封面使用统一占位。

## 已观察问题

1. 真实音乐页面将毫秒时长按秒显示，出现 3519:33；需要按官方音乐数据单位处理。
2. 影视明亮海报下顶部文字对比不足；工具条控件材质与背景分离不清。
3. 音乐绿色大横幅与大片白底偏传统管理页，侧栏、列表、播放器风格不统一。
4. 播放全部实际只消费当前页，须明确播放范围；窄窗口、深色、空状态和播放器遮挡需一起验收。

## 视觉与交互

影视使用炭黑画布、柔和全局背景、玻璃导航与胶囊工具组。海报详情、网格和列表保留现有功能。音乐使用中性色画布与玫红强调色，真实封面叠层、大标题与轻量统计，歌曲行和专辑卡片统一间距。底部播放器、歌词和队列使用同一组磨砂材质与清晰控件。

玻璃有半透明底、背景模糊、细高光边缘和轻阴影；深色单独定义文字/表面值。减少动态效果、高对比度与不支持 backdrop-filter 时提供稳定可读的回退。

## 验收

- 单测验证毫秒时长、未知时长、长音频、实际播放范围、刷新与翻页、封面失败回退。
- 现有影视 hero/详情/播放器、音乐与窗口结构测试通过，客户端 typecheck 和生产构建通过。
- 真实 NAS 检查影视首页/媒体库/详情、音乐歌曲/专辑/歌单/播放条，包含深浅色与窄窗口，确认文字不被背景吞没、最后一行不被播放条遮挡。
- 通过后更新 NAS 静态资源与 UI Docker 版本及 latest；保留备份。原生安装包交由 GitHub Actions，不卡住 UI 验收。
