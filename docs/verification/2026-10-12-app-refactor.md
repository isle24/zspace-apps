## 怎么保证"只是搬家"

1. **每一步都跑类型检查 + 全套用例**：三次拆分，每次之后 `tsc -b` 干净、
   54 文件 / 1154 用例全绿。
2. **确认真的渲染出来**：登录页是未登录状态下唯一能看到的界面，正好用来验 ——
   在 WebKit（Mac 客户端同款引擎）里渲染：

```
页面: {"login":true,"desktop":false,"text":"空间桌面 192.168.3.56:5055 保持登录 "}
控制台异常: 0
```

   原生分支（注入 `__TAURI_INTERNALS__`）也一致：

```
原生客户端 {"fields":["账号","密码"],"sub":"192.168.3.56:5055","toggle":["更改设备地址","独立应用商店"]}
网页版     {"fields":["账号","密码"],"sub":"192.168.3.56:5055","toggle":["更改设备地址","独立应用商店"]}
```

   也就是说：地址栏仍然按"已知地址就隐藏"的逻辑工作，两个入口一致。
3. **构建 + 部署指纹核对**：本地与线上 `assets/client-*.js` 一致。
