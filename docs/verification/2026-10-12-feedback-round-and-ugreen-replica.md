# 用户反馈 11 条 + 绿联云影视复刻：改动与证据

用户在这一轮里提了 11 条界面问题，随后又发来 8 张绿联云影视中心截图要求复刻。
本文把**根因**与**验证方式**逐条记下来 —— 尤其是那些"看起来是 UI 问题、其实是别的东西"的。

## 一、11 条反馈

| # | 反馈 | 真正的根因 | 证据 |
| --- | --- | --- | --- |
| 1 | 相册有些不显示 | 图片加载失败时**没有兜底**，浏览器画破图图标 | 相册 22 张里 2 张失败；现在失败换占位图标，实测 `broken=0` |
| 1b | 相册里有"音乐"字样 | 面包屑对三个媒体模块**共用文案**，相册回退成「音乐 › 歌曲」 | 相册窗口文本里能直接搜到「音乐歌曲」；现在显示「相册 › 时间线」 |
| 1c | 字体被遮挡 | 相册**没走应用外壳**，标题条被 flex 压到 47px 而内容是 62px，副标题溢出到工具栏上 | 实测 hero 47px / 内容 62px；改用外壳后正常 |
| 3 | 相册难看 | 每张图下面挂一行文件名 | 现在只有画面 + 按天分组的日期标题（`cdate`），文件名移到悬停提示 |
| 4 | 影视首页不显示封面 | 设备的分类接口**不返回任何封面字段**（实测原始响应只有 id/名称/数量） | 改为用该库前 4 张海报拼封面：4 个拼图、14 张全部加载成功 |
| 5 | 播放器进度条被"很大的 border"遮挡 | **全局 `input` 样式**给了所有 input `min-height: 40px` + 边框，range 也被画成 40px 大方框 | 实测那个框是 1122×40、1px 边框；排除 range 后进度条恢复 16px |
| 6 | 弹窗不能下拖、上面被遮挡关不掉 | ① 系统栏占 y=10–62（z-index 10000），窗口却开在 y=29；② 拖动约束要求**整扇窗口**都在可视区内，1100×640 只能下移 28px | 修后：窗口开在 y=62；拖 300px 真动 300px |
| 7 | 磁盘 ≥1024G 应显示 TB | `formatBytes` 到 GB 就停了 | 4TB 盘曾显示 `4096.0 GB`；现在到 PB |
| 8 | 系统设置还是参数 | 直接把设备键名当标题（`show_hidden`…） | 现在「显示隐藏文件 → 开启」「分享有效期 → 3 天（259200 秒）」；**没确认含义的键保持原名** |
| 9 | 设备信息还是官方 JSON | `DataValues` 对对象直接 `JSON.stringify` | 现在数组列值、对象显示「N 项」、布尔显示开启/关闭；实测无原始 JSON 文本 |
| 10 | 商店应与三方独立 | 一个窗口塞两个来源 | 拆成**应用商店**（官方）+ **空间商店**（Codex，自绘新图标） |
| 11 | 远程访问应独立 | appId `remote` 渲染的是控制面板外壳（侧栏停在"网络连接"） | 独立的 `RemoteWindow`，只有自己的内容 |

## 二、绿联云影视复刻（6 块）

参照物：用户提供的 8 张截图，规格见 `docs/design-assets/ugreen-reference/video-spec.md`。

| 块 | 还原点 | 实测 |
| --- | --- | --- |
| 侧栏 | 图标导航 + `媒体库` 分组标签 + **圆角浅色选中胶囊**（不是实心蓝块） | 选中态 `rgba(255,255,255,0.1)` / 9px 圆角 |
| 首页 hero | 模糊氛围底 + 清晰海报 + 标题 + 元信息 + 播放胶囊 + **拉长圆点** | 5 个圆点，当前项 26px |
| 封面 | 媒体库用**横排 3 连图**；海报**橙色评分角标** | 4 个拼图 11 张图；角标取设备 `score` |
| 工具条 | 排序（名称/评分/年份）+ **网格/列表**切换 | 点一次变「按名称」，拼音序正确 |
| 详情页 | 模糊大图 + **蓝色播放胶囊** + 圆形操作按钮 + **编号选集** + 演职人员 | `★ 6.1  2026（中国香港 / 中国大陆）  106 分钟  剧情 / 喜剧 / 动作`；33 个选集方块；4 位演职 |
| 播放器 | ±15s + **上下集** + **两端时间码** + 单键倍速 | `上一集/暂停/-15s/+15s/下一集/静音/选集/1.0×/PiP/全屏` |

## 三、做不到 1:1 的地方（诚实记录）

| 绿联有 | 我们 | 原因 |
| --- | --- | --- |
| 横版 backdrop 剧照 | ❌ | 设备一整页 `backdrop` 全空，只有竖版 cover → 用模糊海报代替 |
| 首页最近播放横版缩略图 | ❌ | 无对应接口 |
| 演职人员头像 | ❌ | 只有姓名 → 圆形首字占位 |
| 画质档位 / 字幕轨 | ❌ | 单一转码档、无字幕数据 → **不摆点了没反应的按钮** |
| 已看 / 收藏可切换 | ⚠️ | 设备只读返回 `is_seen`/`is_fav`，客户端无写接口 → 按只读状态显示并注明 |

## 四、这轮顺带修的两处"尺子"

1. **窗口交互的「层叠聚焦」失败** —— 不是应用坏了，是**检查点到了被上层窗口盖住的位置**（诊断加上"命中了谁"后一眼看清）；
2. **窄窗口布局失败** —— 一半是真溢出（工具栏/搜索框/hero 出血 40px），一半是巡检规则过宽
   （把**装饰性容器**也算"静默裁字"）+ 两个真问题（`win=null` 也算 ok、发现问题却退出 0）。
