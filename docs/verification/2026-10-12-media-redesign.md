# 影视 / 音乐 界面精修记录（taste-skill 审计）

日期：2026-10-12。应用 `redesign-existing-projects` 技能的审计清单，对影视中心与音乐做「不改变契约」的精修。
契约仍由 `modules/MediaSkin.test.tsx` 锁定（class / aria / 文案 / 交互），本轮 1102 个用例全绿。

## 审计发现 → 修复

| # | 审计项 | 发现 | 修复 |
| --- | --- | --- | --- |
| 1 | 强调色饱和度 ≥ 80% | 音乐 `#f5222d`、影视 `#0a6cff` 都是高饱和"喊叫色" | 每应用只留一个强调色并压到 80% 以下：影视 `#2b6cd4`、音乐 `#e04a5f`；其余全部中性 |
| 2 | 圆角各自为政 | 卡片 12 / 控件 9 / 播放条 18 / tab 9 混用无规则 | 锁定一套并写进注释：容器 14、卡片 12、控件 9、圆形按钮与胶囊 full |
| 3 | 没有 hover / active / focus 状态 | 卡片与行没有悬停反馈、按钮没有按下反馈、键盘没有焦点环 | 统一补齐：hover 位移+染色阴影、`:active` scale(.98)、`:focus-visible` 2px 强调色圆环、200ms 过渡 |
| 4 | 转圈加载 | 媒体区用通用 spinner | 换成与最终布局同形的**骨架屏**（海报墙 12 格 / 列表 10 行，shimmer 动画） |
| 5 | 卡片副标题是原始英文 | `item.kind` 回落到 `library` / `photo`（半成品观感） | 改为真实元数据：影视 `年份 · 评分`、音乐 `艺人`、相册日期；没有就留空 |
| 6 | 阴影是纯黑 | 悬停阴影 `rgba(0,0,0,.12)` | 改为染色阴影：影视偏蓝、音乐偏红，并统一光源方向 |
| 7 | 重复 CTA 意图 | 左栏与顶栏各有一个「返回媒体库」 | 只保留内容区面包屑旁的一个；导航改为面包屑 `影视中心 › 电影` |
| 8 | 缺 tabular 数字 | 数量/时长用比例数字，跳动 | 计数、时长、进度全部 `font-variant-numeric: tabular-nums` |
| 9 | 海报墙被压扁 | 网格作为 flex 子项被压缩，海报挤成细缝（实测 186×19px） | 内容区可滚动、网格 `flex: 0 0 auto`；海报恢复 2:3（实测 182×273） |
| 10 | 媒体地址缺失 | 海报封面 `/zvideo_static/`、`/zmusic_static/` 不在白名单 | 加入 SDK 白名单与反代放行；实测影视封面 **20/20 加载**（600×900 真海报） |
| 11 | 缺少播放条细节 | 音乐只有原生 audio 控件 | 飞牛式底部胶囊：封面、曲目/艺人、自绘播放暂停、可拖进度、时间、音量、队列、倍速 |
| 12 | 动效无降级 | 未处理系统"减少动态" | `prefers-reduced-motion: reduce` 下关闭全部动画与过渡 |

## 实测结论

- 影视海报墙：`电影 289 / 电视剧 419 / 河蟹 952 / 短剧 0 / 本地 485`，卡片显示真实片名、年份与评分（如 `功夫女足 2026 · 6.1 分`）。
- 音乐：歌曲行显示真实歌名与艺人（此前显示的是专辑名），播放条实测播放中（`0:59 / 3:31`）。
- **音乐封面仍不可用**：`/zmusic_static/<xx>/<hash>.jpg` 即使带上完整 cookie 与 `u=` 参数，极空间音乐服务仍返回 `404 {"message":"Bad Request"}`（直连 5055 实测，非我方代理问题）。界面按"无封面"降级为音符图标，不伪造图片。
