# 音乐歌词面板（对齐 QQ 音乐）

## 端点（差点用错，两个都测了）

| 调用 | 结果 |
| --- | --- |
| `GET /zmusic/api/v2/song/info/lyrics?song_id=…` | **200**，返回真歌词：`{song_lyrics: "[00:00.000] 作词 : Marie Ulven\n[00:29.078] When I see you with her…"}` |
| `POST /zmusic/api/v2/file/info/lyrics`（`song_id`） | 200 但常为空串（纯音乐直接返回空） |
| `GET /zmusic/api/v2/file/info/lyrics` | **404** |

SDK 里原本就有 `music.lyrics` 指向**第一个**（正确的那条），所以没有改动契约 ——
我先按"官方 bundle 里出现的是 /file/info/lyrics"加了新条目，实测对比后撤回并保留了已验证的那条。

## 界面

- 播放条上新增「显示歌词」按钮，面板在胶囊**上方**、同宽展开（实测 720px 对齐）。
- LRC 解析：`[mm:ss.fff]` / `[mm:ss]`、一行多时间戳、`[ti:]/[ar:]` 元信息、
  以及没有时间戳的说明行（例如"此歌曲为没有填词的纯音乐，请您欣赏"）。
- 跟随播放高亮当前行，自动滚动到中间；**点任意一行跳到那一句**；没时间轴时如实说明只显示文字。
- 设备没返回歌词时显示「设备没有返回这首歌的歌词」。

## 实测

真机播放 `-遠い空へ--市川淳.mp3`：歌词面板解析出 **35 行**，
播放到 8 秒时高亮的是 `作曲 : Marie Ulven`（与时间轴一致），首行 `作词 : Marie Ulven` ✓。
