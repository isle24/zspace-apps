# 相册大图查看器

之前点开一张照片只能看完关掉：没有上一张/下一张、不能缩放、键盘完全用不上。
现在补齐成熟看图应用该有的操作。

## 能力

| 操作 | 实现 |
| --- | --- |
| 翻页 | `←` / `→` 或顶部按钮；顶部显示 `当前 / 共几张`；到头时按钮置灰 |
| 关闭 | `Esc` 或「关闭图片」；契约里的「返回相册」保留 |
| 缩放 | 滚轮（**以光标位置为中心**）、双击切换、`+`/`-` 按钮与按键、`0` 复原、`适应窗口` 按钮 |
| 平移 | 放大后按住拖动（Pointer Events + `setPointerCapture`） |
| 预取 | 翻页前预加载相邻两张的**缩略图**（小图，不占内存） |
| 信息 | 底部显示设备真实返回的拍摄时间 / 尺寸 / 体积；没有就写「设备未返回拍摄信息」 |
| 提示 | 底部右侧一行快捷键说明 |

## 两个实现决定

1. **取图仍然走 `ImagePreview`**：那里有 MIME 嗅探、64 MiB 上限、整段校验与错误重试，
   查看器只负责"怎么看"，不重复实现取图逻辑，安全约束不重复也不遗漏。
2. **背景跟随主题**：一开始我给查看器写了深色底（`rgba(10,11,14,.96)`），
   实测被皮肤层的 `.media-module .photo-viewer { background: var(--fn-bg-0) }` 覆盖，
   于是把背景/文字/层级交还给主题，控件改用 `--fn-fill-0 / --fn-bg-3 / --fn-divider / --fn-text-2`。
   浅色应用里突然出现一块深色是设计事故，交给主题变量才是对的。

## 实测（真机，23564 张照片的相册）

- 点开 `IMG_20261007_101711.jpg`：`1 / 20`，底部 `3072 × 4096 · 1.4 MB`，图片正常显示。
- `→` 翻到 `IMG_20261007_101717.jpg`（`2 / 20`），图片加载成功。
- 「放大」→ `150%`，按键 `+` 同样生效；`Esc` 关闭（查看器从 DOM 消失）。
- 顶部按钮齐全：缩小 / 放大 / 适应窗口 / 上一张 / 下一张 / 关闭图片。
