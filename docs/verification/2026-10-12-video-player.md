# 影视播放器重做（对齐 VidHub / HOSPlayer）

日期：2026-10-12。把"能播但像网页 `<video controls>`"的播放体验做成桌面播放器。

## 做了什么

| 能力 | 实现 |
| --- | --- |
| 播放窗口 | 从角落里的小窗改成 **1154×720 的大播放面板**（`min(1180px,94vw) × min(760px,90vh)`） |
| 自绘控制条 | 进度（含**缓冲进度**与可拖拽把手）、播放/暂停、**±10 秒**、静音、音量、时间、选集、倍速、画中画、全屏 |
| 自动隐藏 | 2.5 秒无操作收起控制条**并隐藏鼠标指针**；移动鼠标立即唤回 |
| 手势 | 单击画面播放/暂停、**双击全屏**、**滚轮调音量** |
| 键盘 | 空格/K 播放暂停、←/→ ±10 秒（Shift 为 30 秒）、↑/↓ 音量、M 静音、F 全屏、`[`/`]` 调速、Esc 退出全屏/关闭 |
| 选集抽屉 | 右侧滑出面板，复用当前媒体列表（33 个文件可直接切换），当前项高亮 |
| **记忆播放进度** | 按文件路径存 `localStorage`（`space-desktop:resume:<path>`），每 5 秒记一次；打开时若上次看到 10 秒以上、且距结尾还有 15 秒以上就自动续播 |
| 暂停反馈 | 暂停时画面中央出现大播放键（VidHub/HOSPlayer 的做法） |
| 无障碍 | 所有按钮有 `aria-label`，控制条可键盘操作并带 `:focus-visible` 圆环；`prefers-reduced-motion` 下关闭动画 |

## 实测（真机 + 真片源）

- 影片：`功夫女足`（STRM），时长 **1:46:08**，播放中 `readyState=4`，`currentTime` 持续增长。
- 舞台尺寸 1154×720，画面按 16:9 居中留黑边（`object-fit: contain`）。
- 修复了一个早期遗留：`.global-player video { max-height: 50vh }` 把画面压成半屏，已在播放器作用域内覆盖。
