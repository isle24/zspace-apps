# Docker 旧版兼容与 SSH 安装验收

## 结果与边界

最低引擎版本为 Docker 20.10，Linux AMD64。实际测试版本为 20.10.24、24.0.9、26.1.4；原有极空间 NAS 27.3.1 完成商店升级回归。Docker 没有正式的 22.x 引擎系列，官方版本从 20.10 跳至 23；参见 [Docker API 版本表](https://docs.docker.com/reference/api/engine/)。不能把上述测试解释为每个厂商、内核和文件系统组合都已实测。

镜像继续包含校验固定的 Docker CLI 27.3.1 与 Compose 2.32.4，由客户端协商宿主 API。未固定高版本 API，未放宽非递归挂载、目录身份、只读根目录或容器身份限制。最低 API 1.41 满足原有私有 cgroup 命名空间要求。旧安装器按客户端版本选择等价的挂载语法；20.10–24 使用 `bind-nonrecursive=true`，25+ 使用 `bind-recursive=disabled`。
