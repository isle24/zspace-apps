# 2026-10-15 UI 与商店审查修复

## 本轮确认并修复的问题

- 独立账号模式被误报为 NAS 授权错误；嵌入入口首次创建管理员被引导到无法通过的代理接口。现在显示独立账号提示，并引导直接打开商店初始化。
- 密码会话到期后宿主仍保留已失效会话；iframe 退出没有及时同步。现在按服务端有效期清理，校验来源和 nonce 后同步退出。
- NAS 模式显式退出后被自动登录回来。退出意图跨组件重挂载保留，可主动重新连接；正常到期与主动退出分开处理。
- Tauri 的 iframe 退出消息发错来源。现在回传实际完成握手的宿主来源。
- iframe 卸载可能中断服务端注销。注销请求使用小体积 keepalive POST，本地会话立即清理，异步结果不覆盖新会话。
- 发布目录忽略 URL 图标。现在使用已有受控后端图标地址、GitHub 备用地址和最终字形回退。
- 安装表单中的目录选择、添加、刷新及重试按钮意外提交计划。非提交按钮显式指定 type=button。
- 维护期间仍会先创建目录，再返回维护拒绝。现在创建前检查维护状态，并持有操作锁直到登记结束。
- 同版本云应用按 A→B→A 参数生成计划，第三次可能取到 B；失败重试也可能串用参数。现在绑定本次或原计划核验过的确切配方。
- 旧独立商店无法在升级时增加 UI 来源。现在只允许新镜像为原先没有来源的部署增加明确配置的来源，完整核验旧计划后使用原升级和回滚流程；其他地址、目录、端口、权限变化继续拒绝。
- 来源配置接受浏览器会规范化或拒绝的地址。现在提前拒绝默认端口、大写域名、非规范数字/十六进制主机等不稳定来源。
- Docker 容器列表遗漏托管服务保护标志。列表与实际控制接口共用保护判断。
- 预压缩静态资源忽略 gzip;q=0，普通响应缺少编码缓存区分。现在尊重编码权重，并为各表示设置 Vary。
- 未登录时显示“0 款应用/引擎未就绪”，将尚未读取的状态误作故障。现在提示先登录，登录后读取目录及核验引擎，不开放匿名管理接口。
- README 混有旧端口、未发布状态和旧部署前提。已更新为独立商店及组合部署说明。
