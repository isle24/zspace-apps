# Z4S 初始化与新设备登录修复验收

## 问题与修复

用户报告另一台 Z4S、Docker 26，一键安装出现 `Initializer namespaces changed; all resources were preserved`，UI 登录提示额外验证。未取得该设备现场输出，因此不能声称已在该台 Z4S 上完成验收。

旧启动器未显式设置初始化容器 cgroup/IPC 命名空间，却按私有模式验收。新版创建器明确使用 `--cgroupns private --ipc private`，保留 PID、UTS、权限、挂载和容器身份限制。只替换身份完全匹配、状态为 created、从未启动且无执行记录的旧默认命名空间初始化容器，Docker 删除不带强制参数。旧初次安装意图按完整历史计划、镜像和 socket 组验证，先恢复中断流程，再升级到新镜像。

UI 补齐官方 `N001414` 新设备短信验证流程，其他错误保留官方错误码。发送短信必须由用户主动点击，验证码与 proof 不持久化；真实短信未在本次测试中发送。[协议核验](../research/2026-10-16-nas-login-verification.md)。

- 短信协议与登录界面：34 项通过；客户端全量 82 个测试文件、1357 项通过。TypeScript 与两镜像构建通过。

- 浏览器使用合成 NAS 返回 N001414，最终 UI 镜像显示发送验证码、验证码输入、取消与验证登录按钮；并修正验证码区文字对比度。
