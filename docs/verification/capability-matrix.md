# 能力清单：哪些是**真机验证过**的，哪些不是

维护这份表的理由：这个项目里已经出现过"功能做了、看着能用、**实际从来不生效**"的情况
（剪切板监听，见 `2026-10-12-clipboard-capability.md`）。所以每项能力都标注证据与状态，
**没验证过的一律不算数**。

状态含义：
- ✅ **真机验证**：在 192.168.3.56 这台设备的真实数据/会话上跑过，证据在对应的验证文档里。
- ⚠️ **已知不可用**：验证过，结论是当前条件下做不到，界面已如实说明。
- ⏳ **待验证**：代码在、单测在，但没有在真机上走通成功路径。

## ⚠️ 已验证但当前条件下做不到（界面已如实说明）

| 能力 | 原因 |
| --- | --- |
| 剪切板读取 / 自动监听 | 部署是 http://，非安全上下文，`navigator.clipboard` 不存在 |
| 约 3.5% 的音乐（2,145 WMA + 309 APE + 159 DSD + 40 改名 mp3） | 浏览器无解码器，且设备音乐**不做转码** |
| 音乐封面 | 设备 `/zmusic_static/...` 对它自己返回的地址回 404 |
| 官方 Docker API（`/docker/api/*`） | 本机 9123 未监听（官方 Docker 应用没在跑） |
| 服务端排序（`/v2/file/list` 的 sort/sortby） | 实测十种写法顺序全不变 → 排序只能本地做（已实现为"本页排序"） |

| 项 | 状态 |
| --- | --- |
| 下载单任务 暂停 / 继续 / 删除 | **未实现**：参数名试过 `id`/`gid`/`hash`/`ids`/空体全是 `N202003 参数错误`，设备上 0 个任务无从反推。宁缺勿猜 |
